ミリーちゃん v10

作品の会話モチーフに沿ったLINE会話、10段階の進行、5つの追加結末、名前や相談内容を使わない共有カードをまとめたパッケージです。
SNSで共有しやすい導線を用意していますが、話題化や友だち追加数の増加を保証するものではありません。

まず試す
「ミリーちゃん_作品準拠サンプル.html」をブラウザで開きます。資格情報は不要です。
デモの名前や会話は外部送信・永続保存しません。画面内の制作確認から段階や結末を確認できます。

LINEへの推奨導入
既存LINEのWebhook URLとGASのqueue・push送信を引き継ぐLegacyTransport版を推奨します。
「導入手順.txt」の手順で、既存データを保全してコードを入れ替えます。
従来のGAS直接受信にはLINE署名検証を追加していません。署名を入口で検証する別構成はgatewayフォルダに残しています。

資料
・導入手順.txt：推奨のLegacyTransport版と、任意のGateway版の導入・戻し方。
・仕様と運用.txt：作品との対応、会話・共有・停止・保存・送信の仕様。
・検証結果.txt：自動検証の範囲と、実利用で別途確認する項目。
・リリース記録.txt：本番反映と確認状況の公開用記録。最終状態はこの記録を参照してください。
・hotfix：旧版の誤送信対策を検討した参考資料。v10を再インストールする手順ではありません。

大切な運用条件
initSheets、setupTriggers、旧マイグレーションやclearを、v10の導入手順として実行しません。
既存users・queue・logsの削除や、全ユーザーの履歴・進行の一括初期化は行いません。
公開版とエディタのHEADは別です。時間トリガーはHEADを実行するため、公開版だけを切り替えても処理全体が戻るわけではありません。
認証情報・本番ソースのバックアップ・実デプロイIDは、このパッケージへ含めません。

検証コマンド（Node.js 22以上、rebuildフォルダで実行）
node verify.cjs
